Dit is de Patched source code voor de webpagina die ik als inlog pagina he gemaakt voor het cybersecurity playground project van challenge 2. Ik heb alle zwakheden opgelost en de security holes dicht gemaakt. Alleen login.php is aangepast. Veranderingen zijn een rate Limit, dus hij geeft een timeout na 3x proberen in te breken. En er zit een soort "frame" rondom de databse query waardoor je geen commandos kan injecteren in de database aanvraag.
